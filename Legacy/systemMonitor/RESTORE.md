# Restore the system monitor family and fan control

Parked as one unit on 2026-10-13 in the commit "chore(lightness): park the system monitor family and fan control in Legacy" (`git log --grep "park the system monitor family"`). The ids parked are monitorCPU, monitorGPU, monitorMemory, monitorNetwork, monitorDisk, connectedDevices and fanControl. All of them run on the shared engine in this folder (SystemMonitor, SMCClient, the samplers, MetricDetailView, MonitorSettings, MenuBarRenderer), so they come back together. monitorPower stayed in Sources as the switch for the island's battery notices, resting battery view and accessory batteries; its panel section, menu bar readings, battery alerts and Monitor page were parked here with the engine.

1. Run `Legacy/systemMonitor/restore.sh`. It puts every file in `MOVES.tsv` back where it was (including the per-id folders `Legacy/monitorCPU`, `monitorMemory`, `monitorNetwork`, `monitorDisk`, `connectedDevices`, `fanControl`), and copies the originals in `split/` over the trimmed PowerSampler, MetricFormat, SystemInfo, MenuBarSpacingSupport, NotchAccessoryService, SelfTest and DiskProtectionService.
2. Re-apply the shared-file edits from that commit (`git show <commit> -- <path>`, or `git diff <commit>^ <commit> -- <path> | git apply -R` where it still applies):
   * Core: FeatureCatalog (AppFeature cases, group, symbols, enabledKeys, permissions, installedByDefault, monitor alert pairs), FeaturePresets, Defaults (monitor, menu bar metric, fan and alert keys, registered defaults, sanitizers, migrateFanControlVisibility, migrateBatteryTemperatureVisibility, migrateLegacyMenuBarTemperatureMetric, notchLowBatteryMenuBar), SettingsBackupSupport, Localization.swift and every Localizations/Strings+*.swift (the 115 monitor strings), FeatureHubStrings, GeneralSettingsStrings, NotchEditorStrings, NotchStrings (system), NotchLowBatteryStrings (menuBar), SettingsPageStrings, CommandBarStrings, FeatureStrings (put `MonitorAlertFeatureStrings.swift` from this folder back into it).
   * App: FeatureRuntime (monitor bindings, syncMonitor, fan hardware gate), AppDelegate (metric popover, FanControlService recover/restore, MaxCapacityProbe warm-up, panel resources, hide-icon-with-metrics guards), StatusItemController (metric items, SystemMonitor binding, MenuBarRenderer font), main.swift (`--sensors`).
   * Notch: NotchService (selectedMetric, showMetric, fan detail, system module, monitor demand), NotchSupport (`.system` module, system cards, speedTest control, menuBarBatteryWarning), NotchView, NotchControlsView, NotchDownloadService, NotchLyricsService, NotchContentEditor, NotchSettings.
   * Menu panel and Settings: MenuPanelView, PanelLayout, PanelLayoutEditor, FeatureHubSettings, FeatureVisibilitySupport (`SettingsPage.monitor`, `.fanControl` anchor), SettingsDirectory, SettingsView.
   * Other: CommandBarCatalog and CommandBarService (memory answer), SelfUninstall and Uninstaller (fan helper detach).
3. build.sh: add back the TEST_SOURCES entries, the fan helper compile, its staging into Contents/Library, the DEV plist rewrites, VorssaintFanControlHelperVersion and the codesign steps (`git show <commit> -- build.sh`). The helper source is `Legacy/fanControl/FanControlHelper-main.swift` (MOVES.tsv takes it back to `Sources/FanControlHelper/main.swift`) and its launchd plist goes back to `Resources/`.
4. Tests: MOVES.tsv brings back the parked suites; re-add them to Tests/MetricsTests.swift (metrics, network, force-quit groups), restore the fixtures in Tests/generate_sources.py and the edited suites (FeatureCatalog, Switcher model, Notch destination, Notch, Settings, App management, Update, Notch activity, Repository, SelfUninstall, MenuPanelRecovery, Localization, Clipboard, CommandBar, Preferences) from the commit.
